Icon wrapper around Lucide. The page must load Lucide from CDN first:
`<script src="https://unpkg.com/lucide@0.451.0/dist/umd/lucide.min.js"></script>`

```jsx
<Icon name="shopping-bag" size={22} color="var(--ink-900)" />
```

Only these glyphs are in use: `search`, `shopping-bag`, `map-pin`, `chevron-down`, `chevron-left`, `chevron-right`, `x`, `star`, `minus`, `plus`. Icons are line-only at 2px, never filled, never coloured coral below 24px.
