Pill select. The only form control in the store besides the stepper.

```jsx
<Select label="сортировка" value={sort} onChange={setSort}
  options={["популярные","сначала дешёвые","сначала дорогие","новинки"]} />
```

40px tall, 2px peach-400 border, chevron in coral-700. Options are lowercase; the label is lowercase ink-500.
