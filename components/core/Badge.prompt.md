Status and product-line badge — 12px uppercase caption in a pill.

```jsx
<Badge tone="new" />            {/* новинка */}
<Badge tone="hit" />            {/* хит */}
<Badge tone="soon" />           {/* скоро вернётся */}
<Badge tone="water">water</Badge>
```

Each tone carries its own Russian label, so pass children only to override. One status badge per product card, top-left of the image; line badges appear on the product page above the name.
